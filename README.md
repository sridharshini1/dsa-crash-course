# 🚀 DSA Crash Course

This repository is dedicated to learning and practicing **Data Structures and Algorithms (DSA)**. It's structured as a crash course to quickly build a solid foundation in essential concepts and problem-solving techniques.

**You can view the full course website here:** [dsa-crash-course Live Website](https://sridharshini1.github.io/dsa-crash-course/)
---

## 🎯 Goals of This Course

* **Master** the fundamental Data Structures (Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Hash Maps, Heaps).
* **Understand** essential Algorithms (Searching, Sorting, Recursion, Dynamic Programming).
* **Improve** problem-solving skills for technical interviews.
* **Implement** all concepts in a language like Python/Java/C++ (specify your language).

---

## 📂 Repository Structure

The code and notes are organized by concept:

* `/Arrays`
* `/LinkedLists`
* `/Sorting`
* `/Searching`
* `/Trees`
* `/Graphs`
* ...and so on.

Each folder contains:
* `index.html` (Code for the data structure/algorithm)

## 📖 Getting Started

1.  **Clone** the repository: `git clone https://github.com/sridharshini1/dsa-crash-course.git`
2.  **Practice** by running the implementations and working through the practice problems.
